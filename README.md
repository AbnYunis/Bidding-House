# Bidding House

**Bidding House** is a digital bidding application built using Flutter and Dart, integrated with Firebase for backend services. The app offers a seamless and intuitive platform for users to bid, track bids, and manage auctions, all within a sleek mobile interface.

## Key Features:
1. **All Bids:** View all available bidding types and relevant details.
2. **Search:** A powerful search functionality to find specific bids and participate in them.
3. **My Bids:** Track bids you have placed, and view the status (won or lost).
4. **Auctions:** Manage your published auctions and monitor users who are bidding on your listed items.
5. **Add Bids:** Publish new bids to the app, making them available for all users to join.
6. **Profile:** View and manage your own profile, as well as check out other users' profiles.

## Technologies Used:
- **Flutter & Dart**: Front-end UI and business logic.
- **Firebase**: Backend services for real-time database, authentication, and more.
- **Dependency Injection (DI)**: Modular and scalable architecture.
- **MVVM Pattern**: Ensures clean separation of concerns, facilitating testability and maintainability.
- **Cubit (State Management)**: Efficient state management solution for handling UI state changes.
